# Grad-CAM explanations — SDNET2018

Generated by `python gradcam.py --run runs/gipa_full_0-6x2-0_conv_bs16_random_smote_s42`
from the released weights in `weights/sdnet2018/` (best epoch 46, random split, seed 42).
Test set: 8,414 images, test AUC 0.933 (final exit) / 0.933 (exit 1); decision threshold 0.559 tuned on val (best F1).

| file | what |
|---|---|
| `fig_gradcam_cracked` | 2 correctly detected cracks per surface (Decks, Pavements, Walls) |
| `fig_gradcam_cracked_vs_intact` | intact (TN) vs cracked (TP), one per surface |
| `fig_gradcam_failures` | a missed crack (FN) and a false alarm (FP) per surface |
| `fig_faithfulness` | deletion / insertion curves (`faithfulness.csv`, `faithfulness_curves.csv`) |

Columns: input · Grad-CAM on the conv stem (28×28) · Grad-CAM at pass 1 (exit 1 logit) · Grad-CAM at pass 2 (final logit).
The ViT Grad-CAMs use the input tokens of the last core block, since the head reads only [CLS].

## Faithfulness (200 correctly classified cracked test images)

SDNET2018 has no pixel masks, so the maps are checked by deletion / insertion (Petsiuk et al., 2018):
the most salient pixels are blurred out (deletion) or restored onto a blurred image (insertion).

| saliency map | deletion AUC ↓ | insertion AUC ↑ |
|---|---|---|
| Grad-CAM pass 1 | **0.470** | **0.742** |
| Grad-CAM conv stem | 0.472 | 0.712 |
| Grad-CAM pass 2 (final) | 0.532 | 0.707 |
| random map | 0.659 | 0.646 |

All Grad-CAM maps beat the random baseline on both measures, so the highlighted crack pixels are the ones driving the prediction.
